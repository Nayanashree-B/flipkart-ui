Flipkart UI – E-Commerce Homepage

A responsive e-commerce homepage inspired by Flipkart, built using HTML5 and CSS3.

Features

Header with logo, search bar, Login and Cart buttons

Product category navigation

Promotional banner and featured promotional tiles

Top Deals product section

Footer with informational links

Responsive layout for desktop, tablet and mobile screens

CSS hover effects and styling

Technologies Used

HTML5

CSS3

CSS Grid

Flexbox

Media Queries

Project Structure

Flipkart/
├── index.html
├── style.css
└── README.md

How to Run

Download or clone this repository.

Open the project folder in Visual Studio Code.

Open index.html using the Live Server extension, or open it directly in your browser.
